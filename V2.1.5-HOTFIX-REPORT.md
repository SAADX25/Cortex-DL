# v2.1.5 setup, trim sound and CI fixes

This pass addresses the reported engine setup screen, missing Visual Trim sound control and GitHub Actions installer-test failure. Version remains 2.1.5. No tag, release or remote publication is created.

## Changes

- Startup used one 0% message for the entire verification pass. It now reports the current engine and advances as checks finish. Repair downloads report received/total MB, with unknown-length downloads still reporting received bytes. A continuous scan and dedicated spinner keyframes remain active during checking/repair, including extraction.
- adm-zip synchronously reads and inflates archives. That work now runs in a bounded worker thread, keeping Electron's main event loop available. Existing archive size, expansion, traversal, symlink, duplicate and output allowlist protections remain. Temporary staging, verification and atomic promotion are unchanged. Unexpected worker termination rejects instead of hanging setup.
- Visual Trim always set its video element to muted and depended on Chromium's responsive native controls. It now has an explicit sound toggle and volume slider, starts unmuted without autoplay, and synchronizes native control changes. Trim seeking, fallback, saving and disposal remain covered. A video-only preview source cannot produce audio that is absent from that source.
- The installer CI script wrote seed-legacy.cjs before creating installer-validation. It now creates that directory recursively. A regression test executes the real script in a pristine temporary workspace with installer processes stubbed; it does not install software or touch real user data. Existing real NSIS upgrade coverage remains in CI.
- Packaged smoke additionally verifies ZIP worker module resolution from the installed ASAR layout, moving setup animation and progress, and mute/unmute across twenty trim sessions.

## Validation

Completed before the report was drafted: TypeScript and ESLint passed; 12 hardening tests passed (including ZIP responsiveness, byte progress with/without Content-Length and pristine installer workspace); 5 Visual Trim tests passed, including real Electron playback, sound toggle/volume/native synchronization and 25 disposed sessions. The initial candidate installer build passed.

Full regression passed: 68 tests, 0 failures, 0 skips (275,454 ms). Two-run packaged smoke passed, including ZIP worker loading, setup animation/progress and trim sound controls. Backend resource counts returned to zero. Targeted hardening tests were repeated after the worker termination fix: 12/12 passed. After committing, rebuild from clean source and validate the resulting candidate again; local artifact results belong in app/release/2.1.5/HOTFIX-VALIDATION.md.

The image's frozen-looking 0% verification screen does not itself prove that engines are being downloaded. Healthy bundled engines are checked locally. This pass removes the confirmed synchronous extraction work from the main process and adds visible progress; a remaining device-specific freeze requires its diagnostics.

The GitHub Node 20 action warning is separate from the fatal ENOENT error. This pass fixes that missing-directory error without changing unrelated workflow actions.

Public distribution blockers documented in PRODUCTION-HARDENING-REPORT.md remain, including corresponding FFmpeg source/license review and signing. The existing v2.1.5 tag is not moved. Installing another 2.1.5 build requires reinstalling it manually; equal-version auto-update remains intentionally disabled.
