# v2.1.5 setup, trim sound and CI fixes

This pass addresses the reported engine setup screen, missing Visual Trim sound control and GitHub Actions installer-test failure. Version remains 2.1.5. No tag, release or remote publication is created.

## Changes

- Startup reports local engine verification separately from repair/downloads. Verification runs concurrently with monotonic progress, and a late IPC state snapshot cannot overwrite a newer ready event. Status text stays readable while progress changes. Repair downloads report received/total MB, with unknown-length downloads still reporting received bytes. Spinner animation remains active during checking/repair, including extraction.
- adm-zip synchronously reads and inflates archives. That work now runs in a bounded worker thread, keeping Electron's main event loop available. Existing archive size, expansion, traversal, symlink, duplicate and output allowlist protections remain. Temporary staging, verification and atomic promotion are unchanged. Unexpected worker termination rejects instead of hanging setup.
- Visual Trim has a sound toggle and volume slider beside Reset. It accepts muxed previews and separate progressive video/audio resources, synchronizing playback, pause, seeking, playback rate and volume. Both media resources are released on close. The actual reported YouTube video has no muxed HTTP format: separate resources, rather than codec spelling alone, explain the selection failure. Extraction uses the default network route; the forced IPv4 route returned HTTP 429 during verification. If analysis has no playable direct URL, trim remains available and resolves the source page URL.
- Cortex_Dev.bat exists in the project root and the user's Desktop launcher has been updated to the same content. Both were checked with a stub npm command: they resolve G:\Cortex DL\app and invoke npm run dev. The launcher checks Node, npm and installed Vite dependencies.
- The installer CI script wrote seed-legacy.cjs before creating installer-validation. It now creates that directory recursively. A regression test executes the real script in a pristine temporary workspace with installer processes stubbed; it does not install software or touch real user data. Existing real NSIS upgrade coverage remains in CI.
- Packaged smoke additionally verifies ZIP worker module resolution from the installed ASAR layout, moving setup animation and progress, and mute/unmute across twenty trim sessions.
